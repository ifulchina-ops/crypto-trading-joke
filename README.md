## The joke

> I bought the dip at 3 a.m. Woke up to a deeper dip — my portfolio now has more layers than my lasagne.

A one-liner about every trader's favourite lie: "buy the dip". The dip keeps dipping, the 3 a.m. chart-staring buys nothing, and the portfolio ends up with more layers than lasagne.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Requires Node 22.18+ (runs TypeScript directly). The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
